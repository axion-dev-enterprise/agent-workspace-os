Comparativo Técnico

      
Execução Sem Governança vs Workspace OS

      

        Diferenças estruturais entre execução avulsa de LLMs e um ambiente com governança determinística de workspace.
      

    


    

      

        

          
          Execução Sem Governança
        

        
    
          
  • 
            
            Amnésia de Sessão: Perda de contexto e decisões a cada encerramento de chat.
          
    • 
          
  • 
            
            Conflito de Arquivos: Agentes concorrentes sobrescrevem edições uns dos outros sem trava.
          
    • 
          
  • 
            
            Poluição de Repositório: Criação de arquivos de teste, caches e pastas dispersas na raiz.
          
    • 
          
  • 
            
            Vazamento de Credenciais: Tokens de API e arquivos de ambiente versionados acidentalmente.
          
    • 
          
  • 
            
            Builds Locais Travados: Execução de compilações pesadas no host local consumindo CPU e memória.
          
    • 
        

      


      

        

          
          Execução Sob o Workspace OS
        

        
    
          
  • 
            
            Persistência em Disco: Fila active_tasks.json e status compartilhado em blackboard.json.
          
    • 
          
  • 
            
            Coordenação Multi-Agente: Handoffs estruturados entre Antigravity, Claude e Cursor no mesmo repositório.
          
    • 
          
  • 
            
            Auditoria Automatizada: Linter de qualidade e integridade executado antes de cada commit.
          
    • 
          
  • 
            
            Cofre de Credenciais: Diretório isolado com validação prévia de identidade (Whoami Probe) antes de chamadas de API.
          
    • 
          
  • 
            
            Servidor Local Zero Dependência: Servidor Python nativo (latência <5ms) com deploy automatizado em CI/CD remoto.
          
    • 
        

      

    

  






  

    

      
Arquitetura de Módulos

      
Componentes do Sistema

      

        Serviços integrados que operam no ambiente de desenvolvimento para suporte às operações dos agentes.
      

    


    

      

        

          
        

        
Setup & Control Dashboard (Porta 8765)

        

          Servidor Python ThreadingHTTPServer nativo (zero dependências pip) com diagnóstico de ambiente para Python 3.11, Node.js, Git, GitHub CLI, Vercel e Cloudflare.
        

        

          GET /api/preflight → HTTP 200 OK [3ms] (python, node, git, gh, vercel, wrangler: 100% OK)
        

      


      

        

          
        

        
WhatsApp Client Bridge

        

          Bridge Node.js para pareamento por QR Code. Opera em modo Monitor (gravação de mensagens em JSONL) ou React (enfileiramento de tarefas via /task).
        

        

          PORT 4114 • Status: qr_ready • Mode: monitor / react
        

      


      

        

          
        

        
Fila de Tarefas Multi-Agente

        

          Fila estruturada em workspace/memory/active_tasks.json e quadro de estado em blackboard.json com bloqueio de concorrência.
        

        

          {"tasks": [{"id": "t1", "agent": "claude", "status": "done"}]}
        

      


      

        

          
        

        
Auditor de Qualidade de Código

        

          Rotinas automatizadas de verificação estática que inspecionam integridade de bundles, sintaxe e conformidade de regras antes do versionamento.
        

        

          python audit_anti_slop.py → [PASS] 0 erros
        

      


      

        

          
        

        
Google Drive Sync & RAG Local

        

          Sincronização de documentação corporativa e diretrizes de governança com indexação semântica local em workspace/knowledge_base/.
        

        

          python google_drive_sync.py --sync → 100% OK
