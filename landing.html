Engenharia vs Caos

      
Por Que Agentes Precisam de um Workspace OS?

      

        A diferença entre um agente de IA desgovernado que polui seu repositório e uma equipe autônoma de alta performance.
      

    


    

      
      

        

          
          Sem o Workspace OS (Caos Tradicional)
        

        
    
          
  • 
            
            Amnésia entre sessões: O agente perde o contexto toda vez que uma conversa encerra.
          
    • 
          
  • 
            
            Conflito entre ferramentas: Cursor sobrescreve arquivos que o Claude estava editando sem sincronização.
          
    • 
          
  • 
            
            UI Clichê de IA ("AI Slop"): Emojis em botões, gradientes roxos fluorescentes e cópia sem sentido.
          
    • 
          
  • 
            
            Vazamento de credenciais: Chaves de API e tokens `.env` acidentalmente versionados no Git.
          
    • 
          
  • 
            
            Builds lentos que travam a máquina: O agente tenta compilar pipelines pesados localmente.
          
    • 
        

      


      
      

        

          
          Com o Agent Workspace OS (Padrão AXION)
        

        
    
          
  • 
            
            Memória Compartilhada: Fila active_tasks.json e quadro blackboard.json persistentes no disco.
          
    • 
          
  • 
            
            Co-Work Multi-Agente: Handoffs estruturados permitindo que Antigravity, Claude e Cursor colaborem no mesmo repositório.
          
    • 
          
  • 
            
            Auditoria Anti-AI Slop: Linter nativo que impede emojis em UI, gradientes radioativos e jargões vazios.
          
    • 
          
  • 
            
            Cofre Seguro Isolado: Diretório credentials/ com sonda prévia (Whoami Probe) antes de qualquer mutação.
          
    • 
          
  • 
            
            Zero Build Local: Servidor Python nativo ultrarrápido (<5ms) e esteiras CI/CD remotas rastreáveis.
          
    • 
        

      

    

  







  

    

      
Arquitetura de Produto

      
Features Desenvolvidas para Produção

      

        Sem telas mockadas nem cartões conceituais vazios. Conheça as ferramentas e microsserviços reais integrados ao Workspace OS.
      

    


    

      
      

        

          
        

        
Setup & Control Dashboard Web (Porta 8765)

        

          Servidor Python ThreadingHTTPServer nativo (zero dependências externas) com diagnóstico em tempo real de Python 3.11, Node.js v24, Git, GitHub CLI, Vercel e Cloudflare em menos de 5 milissegundos com cache em memória.
        

        

          GET /api/preflight → HTTP 200 OK [3ms] (python, node, git, gh, vercel, wrangler: 100% OK)
        

      


      
      

        

          
        

        
WhatsApp Client Bridge

        

          Bridge Node.js nativa com pareamento via QR Code instantâneo. Opera em modo Monitor (grava mensagens diárias em JSONL) ou React (enfileira tarefas automáticas via comando /task).
        

        

          PORT 4114 • Status: qr_ready • Mode: monitor / react
        

      


      
      

        

          
        

        
Protocolo Co-Work Multi-Agente

        

          Fila de tarefas compartilhada em workspace/memory/active_tasks.json e status global em blackboard.json, garantindo colaboração assíncrona com zero sobreposição.
        

        

          {"tasks": [{"id": "t1", "agent": "claude", "status": "done"}]}
        

      


      
      

        

          
        

        
Sincronização Google Drive

        

          Conector em Python com autenticação por Service Account que ingere atas de reuniões, gravações e documentos diretamente para o diretório de memória do workspace do agente.
        

        

          python scripts/google_drive_sync.py --sync → OK
        

      


      
      

        

          
        

        
Matriz Canônica de Deploy

        

          Regras determinísticas de hospedagem: frontends estáticos e serverless SPAs na Vercel; backends com estado, bancos PostgreSQL e bots persistentes exclusivamente na VPS/Docker.
        

        

          Vercel (SPAs) • VPS Nó Compute (APIs/Docker)
        

      


      
      

        

          
        

        
Linter & Auditor Automatizado Anti-AI Slop

        

          Auditoria de código estático integrada que inspeciona marcações HTML, JSX, TSX e CSS para impedir vícios de IA generativa: zero emojis em botões/títulos, zero gradientes radioativos de neon e zero métricas falsas.
        

        

          python .agents/skills/axion-anti-ai-slop-design/scripts/audit_anti_slop.py → [PASS] 0 violações
