# Documentação Central — AXION Enterprise

Este diretório contém a documentação técnica, especificações de arquitetura, decisões (ADRs) e regras de execução do ecossistema.

---

## Estrutura de Diretórios

- **`docs/rules/`**: Guardrails técnicos e regras de execução determinística de agentes (`AGENT_EXECUTION_GUARDRAILS.md`).
- **`docs/adr/`**: Registros de Decisão de Arquitetura (*Architecture Decision Records*).
- **`docs/SKILLS_REGISTRY.md`**: Catálogo completo das 58 skills operacionais sincronizadas.
- **`docs/SKILL_SOURCES_GUIDE.md`**: Guia canônico de fontes de skills e protocolo de aprendizado ativo.
