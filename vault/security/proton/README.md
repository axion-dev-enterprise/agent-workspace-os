# Proton Vault & Credenciais 🛡️

## 1. Finalidade
Permitir a configuração de túneis VPN e cofre criptografado seguro para agentes AXION.

## 2. Como Obter Credenciais OpenVPN/WireGuard
1. Acesse o [Proton Account Dashboard](https://account.proton.me/u/0/vpn/WireGuard).
2. Na aba **Downloads / OpenVPN**, copie o usuário e senha específicos para conexões de rede manual.
