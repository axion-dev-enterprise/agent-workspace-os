# Telegram Vault & Credenciais ✈️

## 1. Finalidade
Gerenciar o bot operacional AXION no Telegram para suporte a comandos e recebimento de alertas de infraestrutura.

## 2. Como Obter ou Alterar Token
1. Converse com o [@BotFather](https://t.me/BotFather) no Telegram.
2. Use `/token` ou `/mybots` para gerenciar tokens.
