# Timeline and history

Append one entry per meaningful task using `templates/timeline-entry.template.md`. Include the request, factual diagnosis, actions, result, evidence, limitations, scope, and guardrails. Use local time. Log only sanitized summaries; do not copy credentials, customer data, private URLs, cookies, or message content.

Timeline records support continuity; they do not authorize subsequent actions.
