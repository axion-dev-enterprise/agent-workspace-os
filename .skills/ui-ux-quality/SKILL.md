# UI/UX quality

Use semantic HTML, native controls where possible, visible keyboard focus, labeled inputs, error recovery, and reduced-motion support. Verify responsive layouts and loading, empty, error, and success states.

Use SVG icon systems for interface controls. Avoid decorative system emojis, false metrics, excessive badges, generic card grids, ungrounded marketing claims, and native browser dialogs for critical workflows. Prefer calm surfaces, clear type hierarchy, concrete copy, and data that reflects real product state.
