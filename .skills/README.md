# Workspace skills

The root skills are portable operating modules. Read `SKILL.md` before using one. Optional integrations remain disabled until enabled in the local capability policy; vendored skills retain their upstream source and license details in `docs/EXTERNAL_SKILLS.md`.

| Skill | Use when |
| --- | --- |
| `prompt-intake` | Interpreting a user request, constraints, authorization, and success criteria. |
| `context-memory` | Loading project context and recording durable, sanitized findings. |
| `timeline-history` | Appending a factual local activity record. |
| `operation-preflight` | Preparing a mutation, release, deployment, or connector action. |
| `ui-ux-quality` | Designing or reviewing an interface. |
| `release-management` | Preparing a reviewable version, PR, tag, or release. |
| `template-customization` | Materializing a local workspace from neutral templates. |
