Como configurar credenciais

Passos para habilitar a Google Drive API:

  1. Acesse console.cloud.google.com e crie um projeto.
  2. Ative a Google Drive API.
  3. Crie uma Conta de Serviço e baixe a chave JSON.
  4. Salve o JSON em:
credentials/google_service_account.json
python scripts/google_drive_sync.py --check
