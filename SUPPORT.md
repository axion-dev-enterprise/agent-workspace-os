# Support

Use the repository issue templates for reproducible bugs and scoped feature requests. Include the OS, agent platform, version, sanitized output, and the smallest reproduction possible.

For help adopting the workspace, start with [README.md](README.md), then follow [SETUP_PROTOCOL.md](SETUP_PROTOCOL.md), [WORKFLOW.md](WORKFLOW.md), and the documentation index in [docs/README.md](docs/README.md).

Do not use public issues for credentials, private workspace state, personal data, security vulnerabilities, or support requests that require access to a third-party account. Use [SECURITY.md](SECURITY.md) for security reports.
